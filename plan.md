Create a modern responsive web app called **“PulseCanvas”** — an elegant audio visualizer platform with a clean minimal aesthetic inspired by Apple Music, Linear, and modern music interfaces.

Main Features:

* Users can:

  * Paste a YouTube URL to play embedded audio/video
  * Upload local audio files (.mp3, .wav)
* Real-time animated audio visualizer
* Multiple visualizer styles selectable from a sidebar/dropdown
* Dark mode and light mode toggle
* Smooth UI transitions and subtle animations
* Responsive for desktop and mobile

Design Style:

* Minimalist
* Clean spacing
* Soft rounded corners
* Modern typography
* Slight premium glassmorphism
* Elegant gradients
* No cluttered UI
* Premium music-tech feeling
* Floating UI elements
* Airy layout with depth and soft shadows
